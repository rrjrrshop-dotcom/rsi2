# Stocking — 개인용 주식 전략 분석기 (개발 중)

미국 주식·ETF 종가의 RSI(2), 200일·5일 이동평균을 확인하는 개인용 웹 앱입니다. 매수 조건은 종가 > 200일선 및 RSI(2) < 5, 보유 후 청산 조건은 종가 > 5일선입니다. 별도의 손절 규칙은 없습니다.

## 다섯 전략 탭
1000 · trend · box · RSI2 · breakout 순서의 탭을 제공합니다. RSI2와 1000 일봉 종목 직접 분석을 제공합니다. trend · box · breakout 일봉 분석을 제공합니다. 1000 상세에는 EMA 위치·배열과 MACD·스토캐스틱으로 계산한 9점 만점의 추정 스코어를 표시합니다. 원본 산식은 확인되지 않았습니다. 15분봉은 일봉과 같은 거래일의 EMA 방향을 참고 비교하며, 원본 합의 산식은 확인되지 않았습니다. 1000은 원본 점수 대신 EMA 위치 기준 참고 목록을 제공합니다. RSI2의 API, 저장 키와 알림은 기존 상태를 유지합니다. 모바일에서는 조회와 차트를 우선 표시하고 검색·보유·알림 등은 펼쳐서 확인합니다.

## 현재 상태
- CSV를 이용한 브라우저 내 분석 및 보유 정보 관리, 일봉·거래량·RSI 차트 코드는 구현되어 있습니다. 시고저 데이터가 없으면 종가선을 표시합니다.
- Massive 종가 API, GitHub Actions 예약 검색, Upstash 결과·알림 등록 저장이 연결되어 있습니다. 2026-11-14 전체 검색에서 다섯 탭의 추천 6개씩을 생성하고 저장했습니다. 알림 작업도 정상 종료했으며 이번 실행의 신규 발송은 0건입니다. 실제 기기 도착 여부는 이 실행으로 검증하지 않았습니다.
- 나스닥 상장 주식·ETF, 다우 및 S&P 500 구성 종목이 대상입니다. 다우와 S&P 500은 위키백과 공개 목록으로, 공식 지수 목록과 차이 또는 갱신 지연이 있을 수 있습니다. 러셀 3000은 별도 검색 대상에서 제외했습니다. 다른 검색 범위에 해당하는 러셀 종목은 포함됩니다.
- UGI·CRWD 과거 사례의 5일선과 RSI는 화면의 표시 자릿수에서 비교했지만, 200일선과 전체 결과의 일치율은 아직 검증하지 않았습니다.

## CSV 사용
`Date,Symbol,Close` 열과 각 종목별 최소 200개 거래일이 필요합니다. 한 종목만 포함할 때 `Symbol`을 생략할 수 있습니다. `Open,High,Low,Volume` 열을 제공하면 캔들과 거래량을 표시합니다. 날짜는 `YYYY-MM-DD` 형식이어야 하며 확정된 정규장 종가인지는 사용자가 확인해야 합니다.

## 설치·배포 설정
1. 저장소 최상단에 이 폴더의 **내용물**을 올립니다. `.github` 폴더도 필요합니다.
2. Massive 개인용 데이터 계정과 Upstash Redis 저장소가 필요합니다. 실제 무료 한도·조건과 지연 시간은 사용 전 확인해야 합니다.
3. Node.js 20 이상에서 `node scripts/create-local-config.mjs`를 실행하면 `.env.local`이 생성됩니다. 기존 파일이 있으면 덮어쓰지 않습니다. 이 파일에 서비스 키와 본인 연락용 이메일을 입력합니다. 파일과 비밀값을 GitHub에 공개하지 마세요.
4. Vercel의 환경 변수에는 `MASSIVE_API_KEY`, `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`, `PAIRING_SECRET`, `VAPID_PUBLIC_KEY`를 설정해야 합니다. GitHub Actions의 Secrets에는 이 중 데이터·저장소 관련 항목과 `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`가 필요합니다. VAPID 값은 앱과 예약 작업이 같은 쌍을 사용해야 합니다.
5. 각 기기의 브라우저에서 처음 코드를 인증하면 `PAIRING_SECRET`이 해당 브라우저에 저장되어 조회와 알림 설정에 재사용됩니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 브라우저 사용 또는 코드 변경 시 재입력이 필요합니다. 공용 기기는 사용하지 마세요. 청산 알림을 원하는 경우 앱에서 보유 종목 코드를 별도로 서버에 저장해야 합니다. 매수가·수량은 전송하지 않습니다. 기기 간 자동 동기화는 없습니다. 아이폰 웹 푸시는 홈 화면에 추가한 웹 앱에서 설정해야 합니다.
6. 나스닥 종목 목록에 분류되지 않은 항목이 있거나 위키백과 표를 읽을 수 없으면 전체 검색은 안전을 위해 중단됩니다. 제공처의 요청 제한으로 첫 검색이 오래 걸릴 수 있으며, 현재 구현은 매번 과거 데이터를 다시 요청합니다.

현재 저장소의 서비스 연동은 [자동 검색 검증 기록](research/live-scan-validation.md)에 확인 범위를 남겼습니다. 다른 계정이나 새 배포에는 위 설정을 별도로 적용해야 합니다. `.env.local`은 로컬 파일이며 자동으로 Vercel이나 GitHub에 설정되지 않습니다.

## 검증
`npm test`로 가상 데이터 기반 테스트를 실행합니다. 실제 서비스를 시험한 결과를 뜻하지 않습니다.

GitHub 공개 저장소의 예약 작업은 저장소 활동이 60일간 없으면 자동으로 중단될 수 있으며 예약 실행도 지연될 수 있습니다. Actions 탭에서 실행 상태를 주기적으로 확인하고 필요한 경우 다시 활성화하세요.

## 1000 탭 계산 방식
분할 조정된 일봉 OHLC에서 하이킨아시를 계산한 뒤 EMA 8/13/21/55, MACD 12/26/9, 슬로 스토캐스틱 14/3/3을 적용합니다. 원본의 구체적인 초기화와 지표 설정이 미확인이라 결과 일치는 검증되지 않았습니다. 기준가가 3개 EMA 위에 있는 개수별 참고 비중을 0/30/60/100%로 표시합니다. 실제 매매 지시가 아닙니다. 시간대 합의는 같은 거래일의 EMA 구도를 비교합니다.

## 종목 목록과 상세
각 탭은 재무·시총 필터를 통과한 종목 중 전략별 참고 점수 순으로 최대 6개를 추천합니다. 종목을 누르면 별도 조회로 조건과 차트를 불러옵니다. 추천 점수와 RSI2 매수 신호는 구분하며, 알림은 기존 RSI2 조건을 사용합니다. 1000 추천 순위는 HA 종가가 세 EMA 위인 비율을 사용하고 상세의 추정 스코어는 별도로 표시합니다.

## trend 탭
직접 조회 시 추세 템플릿에서 확인된 일곱 조건과 SPY 대비 가중 상대강도 미확인을 표시합니다. 1개월은 21거래일 전 200일선과 비교하는 근사치입니다. 52주 고저는 최근 252거래일 고가/저가입니다. 원본 가중수익률 산식이 없어 총 통과 여부는 제공하지 않으며, 확인된 7개 조건의 참고 순위만 제공합니다. 조회·차트 확대는 실서비스 및 기기 테스트 전입니다.

## box 탭
직접 조회 시 각 주의 최신 일봉 종가를 이용한 30주 SMA와 직전 50일 평균 거래량 대비 배수를 표시합니다. 주중 값은 미확정 주봉을 포함합니다. 박스 상하단은 직전 60거래일의 일봉 거래량을 가격 구간에 균등 배분한 누적 15~85% 범위로 추정합니다. 실제 매물대가 아닌 근사치이며 직접 상하단을 입력해 교체할 수 있습니다. 원본 단계 판정과 순위는 제공하지 않습니다. 원본과의 일치 및 실제 데이터 검증 전입니다.

## 공통 거래량 분포 참고
다섯 탭의 종목 직접 조회에서 일봉 기반 거래량 분포 추정 구간과 현재 위치를 표시합니다. 당일을 제외한 최근 60일의 고저 범위에 거래량을 균등 배분한 근사치로 실제 매물대가 아닙니다. 전략의 조건과 스코어, 자동 검색과 알림 조건에는 영향을 주지 않습니다.

## 통합 자동 검색 참고 목록
350거래일을 조회하여 전략별 점수를 계산하고, 재무·시총 필터를 통과한 종목 중 각 탭에 최대 6개를 표시합니다. 동점이면 티커 순입니다. 원본 점수·단계 판정이 아니며 상대강도나 원본 박스 생성식 검증을 포함하지 않습니다. 공통 가격 이력이 부족한 종목과 OHLC 오류는 제외됩니다. 350회 시세 요청은 분당 5회 무료 한도 때문에 약 76분 이상 걸릴 수 있습니다. 재무자료 조회를 포함한 첫 성공 실행은 약 117분이 걸렸으며 실행 제한은 180분입니다. 예약은 한국 시간 화요일~토요일 20시입니다. 저장 완료 후 앱에서 검색 결과를 다시 불러오면 갱신됩니다.

SPY 자체 조회는 SPY 대비 가중수익률이 자기 자신과 같아 상대강도 상회 조건을 미충족으로 처리합니다. 다른 종목은 가중 산식 미확인으로 유지하며 자동 참고 순위는 모든 종목에 동일하게 7개 조건만 사용합니다. 화면의 반올림 숫자 기준 대조는 실제 시계열 재현 검증이 아닙니다.


### Breakout
확정 종가를 직전 20·55거래일 고점 및 20거래일 저점과 비교합니다. 20일 ATR은 와일더 평활을 사용하며, 2N 손절과 0.5N 간격 추가 진입을 종목별 배분액 기준으로 계산합니다. 원본 서비스 ATR 산식과는 다를 수 있습니다. 상위 목록은 55일 돌파 우선, 20일 돌파선으로부터 ATR 기준 거리가 가까운 순이며, 자동 검색 완료 후 갱신됩니다. 무료 일봉 데이터의 갱신 지연과 과거 검색 결과 여부에 주의하세요.


### 관심종목과 추천

추천은 자동 검색 대상 중 SEC 공시로 발행주식 수를 확인할 수 있는 주식에 적용합니다. Massive의 기준일 비조정 종가에 발행주식 수를 곱해 시가총액을 추정하며, 공시 이후 분할을 반영합니다. 시총을 확인한 종목에서 하위 30%를 올림해 제외하고, 경계 시총과 같은 종목도 제외합니다. 최근 180일 이내의 공시에서 자본이 양수이고 자산이 부채보다 커야 합니다. 유동자산과 유동부채가 모두 공시된 경우에는 유동자산이 유동부채 이상이어야 합니다. ETF, 우선주, 예탁증서, 공시로 시총이나 건전성을 확인할 수 없는 종목은 추천에서 제외합니다. 필터를 통과한 종목이 6개보다 적으면 확인된 종목만 표시합니다. 자료 조회 실패 시 자동 검색은 시세 이력 수집 전에 중단되며 직전 저장 결과를 유지합니다.

예약 검색은 Massive의 기준일 보통주 목록에서 티커와 SEC 기업 식별자(CIK)를 연결하고, [Quotelinks SEC Fundamentals API](https://www.quotelinks.com/api/sec-fundamentals/)에서 공시 재무자료를 읽습니다. GitHub 실행 환경에서 SEC 직접 요청이 거절되어 공시 데이터 제공 경로를 변경했습니다. 별도의 API 키 없이 초당 2건 미만으로 요청하며, 최초 보고 기준(`basis=original`)을 사용합니다. 기준일 이후 공시, 오래된 자료, 분할 조정·추정 주식 수는 사용하지 않습니다. 공시 기간 말과 제출일 사이에 분할이 있으면 주식 수의 기준이 불확실하므로 제외합니다. 여러 보통주 티커가 같은 기업에 연결되면 기업 전체 주식 수로 개별 주식의 시총을 계산할 수 없어 추천 대상에서 제외합니다.

Quotelinks의 이용 범위는 개인의 비공개·비상업적 분석입니다. 원본 재무자료를 저장소나 공개 로그에 게시하지 않으며, 앱 결과는 개인 접근 코드로 보호합니다. 외부 사용자에게 결과를 제공하는 서비스로 변경할 때는 데이터 공급자의 사용 허가가 필요합니다. `.github/workflows/check-fundamentals.yml`은 재무 API의 응답과 날짜·분할 기준을 검사합니다. 필터와 스캔 코드가 main에 반영되면 자동 검색이 실행되며 기존 일일 예약도 유지됩니다.

한 브라우저에 최대 10개 관심종목을 저장하며 탭에서 공유합니다. 등록 시 Massive의 활성 미국 증권 정보로 확인합니다. 연결 또는 권한 오류 시 등록하지 않습니다. 저장 결과는 기기 간 동기화되지 않습니다. 각 탭의 임시 점수는 앱에 산식이 표시되며 원본 서비스의 점수가 아닙니다. 종목별 점수는 조회 가능한 확정 일봉으로 계산합니다. 추천은 최신 완료된 자동 검색에서 전략 점수 순으로 최대 6개 표시합니다. 무료 데이터 요청 한도로 조회가 실패하거나 지연될 수 있습니다. 차트 이미지 보기 버튼은 해당 차트를 캡처해 보여주며, 원본 참조 화면과 픽셀 단위 일치는 보장하지 않습니다.


### 이용 방법과 PDF
이용 방법 탭에 전략별 안내를 제공합니다. 상세 결과의 PDF 저장은 조건과 점수, 차트, 상황별 참고를 A4 한 페이지 이미지형 PDF로 생성합니다. 항목이 많으면 요약하여 표시합니다. ATR 1유닛 위험은 설명서의 2N 손절 시 배분액의 1%를 기본으로 하며 예전 화면의 약 2%도 선택할 수 있습니다. ATR 방식과 상대강도 원본 산식은 확인되지 않았습니다. box의 30주선 기울기는 직전 주와 비교한 참고값이며 네 단계의 정식 판정은 아닙니다.


### 1000 시간대 연결
티커만 입력하면 일봉을 기본으로 표시합니다. 같은 거래일에 완결된 정규장 15분봉의 EMA1·2·3 대비 EMA5를 내부 참고 지표로 비교해 일봉 결과와 함께 표시합니다. 화면의 혼조·상승·하락은 일봉과 15분봉의 EMA 구도를 비교한 결과입니다. 데이터가 없거나 다른 날짜 또는 정규장 마지막 봉이 없으면 비교 불가로 표시합니다 (조기 폐장도 비교 불가). 추천 자동 검색은 1000 탭의 추천 종목에 대해 내부 비교를 저장합니다. 일봉 기반 추천 순위는 변경되지 않습니다. 무료 계정의 종가 및 분봉 요청 한도와 지연으로 데이터 확인이 실패할 수 있습니다.


### 1000 스코어
1000 상세의 추정 스코어는 `max(1, EMA8·13·21 중 EMA55 위인 개수) + (EMA8 > EMA13) + (EMA13 > EMA21) + 2×(MACD > 시그널) + 2×(K > D)`입니다. 참은 1, 거짓은 0으로 계산합니다. 일봉 예시 30건 중 29건 일치, 평균 절대오차 0.033점이며 PLTR은 원본 4점에 대해 3점입니다. 이 30건을 보고 식을 선정했으므로 독립 검증 성능이 아닙니다. 원본 점수·매매 신호로 확정하지 않으며 기존 자동 추천 순위와 알림에는 사용하지 않습니다. [전체 후보식 비교](research/score-comparison.md)는 `node research/compare-weighted-score.mjs`로 재현합니다. 이미지의 인쇄된 지표와 점수 사이의 비교이며, 실제 OHLC로 계산한 지표가 원본과 일치한다는 의미는 아닙니다.
