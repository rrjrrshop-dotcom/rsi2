# Stocking — 개인용 주식 전략 분석기 (개발 중)

미국 주식·ETF 종가의 RSI(2), 200일·5일 이동평균을 확인하는 개인용 웹 앱입니다. 매수 조건은 종가 > 200일선 및 RSI(2) < 5, 보유 후 청산 조건은 종가 > 5일선입니다. 별도의 손절 규칙은 없습니다.

## 다섯 전략 탭
1000 score · trend score · box score · rsi2 score · breakout score는 확정 일봉의 조건 충족 수입니다. `6/8점 · 75점`은 8개 조건 중 6개 충족을 뜻합니다. 100점 환산은 충족 수를 전체 조건 수로 나눈 값이며, 소수점 첫째 자리까지 표시합니다. 초록 체크는 충족, 빨간 ×는 미충족, 회색 선은 미확인입니다. 각 줄에는 판단에 사용한 수치를 표시합니다.

## 현재 상태
- CSV를 이용한 브라우저 내 분석 및 보유 정보 관리, 일봉·거래량·RSI 차트 코드는 구현되어 있습니다. 시고저 데이터가 없으면 종가선을 표시합니다.
- Massive 종가 API, GitHub Actions 예약 검색, Upstash 결과·알림 등록 저장이 연결되어 있습니다. 2026-11-14 전체 검색에서 다섯 탭의 추천 6개씩을 생성하고 저장했습니다. 알림 작업도 정상 종료했으며 이번 실행의 신규 발송은 0건입니다. 실제 기기 도착 여부는 이 실행으로 검증하지 않았습니다.
- 추천의 주요상장사 범위는 나스닥 100·S&P 500·다우의 합집합, 전종목 범위는 시총 상위 80%의 미국 상장 보통주입니다. RSI2 신호 검색에는 나스닥 상장 주식·ETF와 지수 구성 종목을 사용합니다.
- UGI·CRWD 과거 사례의 5일선과 RSI는 화면의 표시 자릿수에서 비교했지만, 200일선과 전체 결과의 일치율은 아직 검증하지 않았습니다.

## CSV 사용
`Date,Symbol,Close` 열과 각 종목별 최소 200개 거래일이 필요합니다. 한 종목만 포함할 때 `Symbol`을 생략할 수 있습니다. `Open,High,Low,Volume` 열을 제공하면 캔들과 거래량을 표시합니다. 날짜는 `YYYY-MM-DD` 형식이어야 하며 확정된 정규장 종가인지는 사용자가 확인해야 합니다.

## 설치·배포 설정
1. 저장소 최상단에 이 폴더의 **내용물**을 올립니다. `.github` 폴더도 필요합니다.
2. Massive 개인용 데이터 계정과 Upstash Redis 저장소가 필요합니다. 실제 무료 한도·조건과 지연 시간은 사용 전 확인해야 합니다.
3. Node.js 20 이상에서 `node scripts/create-local-config.mjs`를 실행하면 `.env.local`이 생성됩니다. 기존 파일이 있으면 덮어쓰지 않습니다. 이 파일에 서비스 키와 본인 연락용 이메일을 입력합니다. 파일과 비밀값을 GitHub에 공개하지 마세요.
4. Vercel의 환경 변수에는 `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`, `PAIRING_SECRET`, `VAPID_PUBLIC_KEY`를 설정해야 합니다. GitHub Actions의 Secrets에는 `MASSIVE_API_KEY`, Upstash 저장소 관련 항목과 `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`가 필요합니다. VAPID 값은 앱과 예약 작업이 같은 쌍을 사용해야 합니다.
5. 각 기기의 브라우저에서 처음 코드를 인증하면 `PAIRING_SECRET`이 해당 브라우저에 저장되어 조회와 알림 설정에 재사용됩니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 브라우저 사용 또는 코드 변경 시 재입력이 필요합니다. 공용 기기는 사용하지 마세요. 청산 알림을 원하는 경우 앱에서 보유 종목 코드를 별도로 서버에 저장해야 합니다. 매수가·수량은 전송하지 않습니다. 기기 간 자동 동기화는 없습니다. 아이폰 웹 푸시는 홈 화면에 추가한 웹 앱에서 설정해야 합니다.
6. 나스닥 종목 목록에 분류되지 않은 항목이 있거나 위키백과 표를 읽을 수 없으면 전체 검색은 안전을 위해 중단됩니다. 새 저장소에서는 Actions의 Daily market scan을 실행해 최근 350거래일 일봉을 한 번 채웁니다. 이후에는 마지막 저장일 이후의 거래일을 추가합니다.

현재 저장소의 서비스 연동은 [자동 검색 검증 기록](research/live-scan-validation.md)에 확인 범위를 남겼습니다. 다른 계정이나 새 배포에는 위 설정을 별도로 적용해야 합니다. `.env.local`은 로컬 파일이며 자동으로 Vercel이나 GitHub에 설정되지 않습니다.

**테스트 알림 보내기**는 현재 브라우저에 등록된 기기로만 테스트 알림을 보냅니다. 앱에서 접수 메시지를 본 뒤 기기의 알림 창에서 실제 수신을 확인하세요.

안내 탭에서 **1. 휴대폰 알림 등록**과 **2. 보유 종목**을 엽니다. 보유 종목은 수기 입력 또는 JPG·PNG·WebP 화면을 읽어 등록할 수 있습니다. 이미지는 브라우저에서 읽으며, 미리보기에서 확인해 선택한 행만 저장합니다. 매입가가 화면에 없으면 보유수량과 USD 평가금액·평가손익으로 계산한 추정값을 별도로 표시합니다. 중복 티커는 기존 항목을 덮어쓰지 않습니다.

각 전략의 **자동 검색 결과**는 거래일 배치가 보관한 전략별 후보를 보여 줍니다. RSI2는 매수 신호 목록입니다. 추천 카드와 자동 검색 후보는 서로 다른 목록이며, 자동 검색 옆 스코어는 같은 날짜의 저장된 일봉으로 계산합니다.

### 알림 기준

종합 → 알림 등록에서 브라우저 푸시를 등록하고 **보유·관심 종목 알림 저장**을 누릅니다. 관심 또는 보유 목록을 변경한 기기에서 다시 저장하세요. 서버에 종목 코드와 등록한 문자 번호가 저장됩니다. 최신 확정 일봉 계산에서 충족으로 바뀐 조건을 아래 순서로 보냅니다.

1. 보유종목 청산 조건. 1000은 하이킨아시 종가의 EMA55 하회, trend는 참고용 200일선 이탈, box는 추정 박스 하단 이탈, RSI2는 5일선 상회, breakout은 S1 10일 저점·S2 20일 저점 하회입니다.
2. 보유종목 진입 조건. 전략별 환산 스코어가 처음 100점에 도달하면 알립니다. 같은 전략에서 100점 미만으로 내려갔다가 다시 100점에 도달하면 재발송합니다.
3. 관심종목 조건 충족. 해당 전략에서 판정 가능한 진입 조건 전체를 충족하기 시작할 때 알립니다.
4. 추천종목 신규 진입. 저장된 주요상장사·전종목 추천 목록에서 전략별 새 편입이 발생할 때 알립니다. 첫 실행은 비교 기준을 저장합니다.

PC에서도 브라우저 푸시를 받거나 문자 번호를 저장할 수 있습니다. SMS를 사용하려면 Twilio에서 발신 번호와 수신 번호를 확인하고 GitHub Actions Secrets에 `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM_NUMBER`, `TWILIO_VERIFIED_TO`를 설정합니다. 준비가 완료되면 Vercel Production 환경에 동일한 `TWILIO_VERIFIED_TO`와 `TWILIO_SMS_ENABLED=true`를 넣고 재배포합니다. Twilio에서 확인한 수신 번호와 일치할 때만 문자를 보냅니다. 같은 거래일의 알림은 문자 한 건으로 합쳐 발송 요청합니다.

## 검증
`npm test`로 가상 데이터 기반 테스트를 실행합니다. 실제 서비스를 시험한 결과를 뜻하지 않습니다.

GitHub 공개 저장소의 예약 작업은 저장소 활동이 60일간 없으면 자동으로 중단될 수 있으며 예약 실행도 지연될 수 있습니다. Actions 탭에서 실행 상태를 주기적으로 확인하고 필요한 경우 다시 활성화하세요.

## 1000 탭 계산 방식
분할 조정된 일봉 OHLC에서 하이킨아시를 계산한 뒤 EMA 8/13/21/55, MACD 12/26/9, 슬로 스토캐스틱 14/3/3을 적용합니다. 원본의 구체적인 초기화와 지표 설정이 미확인이라 결과 일치는 검증되지 않았습니다. 기준가가 3개 EMA 위에 있는 개수별 참고 비중을 0/30/60/100%로 표시합니다. 실제 매매 지시가 아닙니다. 시간대 합의는 같은 거래일의 EMA 구도를 비교합니다.

## 종목 목록과 상세
각 전략의 **주요상장사** 또는 **전종목** 이미지를 선택하면 재무·시총 기준을 통과한 종목을 충족 조건이 많은 순으로 최대 6개씩 보여 줍니다. 추천 카드의 **조건 자세히**에서 판정과 비교 수치를 확인할 수 있습니다. 종목을 누르면 일봉 상세가 열립니다. RSI2 알림은 200일선 및 RSI(2) 규칙을 사용합니다.

| 점수 | 점수에 포함하는 조건 | 보유 시 청산 기준 |
|---|---|---|
| 1000 score | 9개. 단기 EMA 정배열, 종가의 EMA21 상회, 종가의 EMA55 상회, 직전·당일 EMA55 위 유지, 단기 EMA 3개가 EMA55 위, 최근 삼선 교차 없음, 삼선 게이지, MACD, 스토캐스틱 | 상세에서 EMA55와 종가의 위치 확인 |
| trend score | 8개. 종가가 150·200일선 위, 150일선 > 200일선, 200일선 상승, 50·150·200일선 정배열, 종가 > 50일선, 52주 저점보다 30% 이상 높음, 52주 고점에서 25% 이내, SPY 대비 가중 상대강도 | — |
| box score | 4개. 종가 > 30주선, 30주선 상승, 박스 상단 돌파, 50일 평균 거래량의 2배 이상 | 상세에서 박스 하단 확인 |
| rsi2 score | 2개. 종가 > 200일선, RSI(2) < 5 | 종가 > 5일선 |
| breakout score | 2개. 종가가 각각 직전 20·55일 고점을 돌파 | S1은 10일 저점, S2는 20일 저점 이탈 |

## trend 탭
1개월은 21거래일 전 200일선과 비교합니다. 52주 고저는 최근 252거래일의 고가와 저가입니다. SPY 대비 가중 상대강도 산식은 미확인으로 표시하며, 확인된 충족 수를 전체 8개 조건의 분모와 함께 보여 줍니다. SPY 자체 조회는 비교 기준과 같으므로 상대강도 우위 조건이 미충족입니다.

## box 탭
직접 조회 시 각 주의 최신 일봉 종가를 이용한 30주 SMA와 직전 50일 평균 거래량 대비 배수를 표시합니다. 주중 값은 미확정 주봉을 포함합니다. 박스 상하단은 직전 60거래일의 일봉 거래량을 가격 구간에 균등 배분한 누적 15~85% 범위로 추정합니다. 실제 매물대가 아닌 근사치이며 직접 상하단을 입력해 교체할 수 있습니다. 원본 단계 판정과 순위는 제공하지 않습니다. 원본과의 일치 및 실제 데이터 검증 전입니다.

## 공통 거래량 분포 참고
다섯 탭의 종목 직접 조회에서 일봉 기반 거래량 분포 추정 구간과 현재 위치를 표시합니다. 당일을 제외한 최근 60일의 고저 범위에 거래량을 균등 배분한 근사치로 실제 매물대가 아닙니다. 전략의 조건과 스코어, 자동 검색과 알림 조건에는 영향을 주지 않습니다.

## 통합 자동 검색 참고 목록
최근 350거래일의 시고저종·거래량을 개인 접근 코드로 보호되는 Upstash에 저장합니다. 각 거래일에 미국 동부 시간 20시 30분에 Massive의 미국 시장 일봉을 한 번 묶음으로 받아 추가합니다. 무료 Stocks Basic의 데이터 공개는 20시 15분이며, 20시 30분은 시간외 거래 종료 후 30분입니다. 한국 시간으로 다음 날 오전 9시 30분(서머타임) 또는 오전 10시 30분입니다. [Massive 데이터 공개 시간](https://massive.com/changelog)

검색은 같은 저장본으로 5개 전략과 두 종목 범위를 계산합니다. 완성된 추천과 일봉은 함께 게시합니다. 예약 작업의 미국 동부 시간 00시 30분 실행은 아직 게시하지 못한 거래일을 복구하며, 이미 게시한 거래일은 Massive에 요청하기 전에 종료합니다. 시세가 준비됐지만 추천 처리에서 오류가 난 경우 저장한 당일 시세를 재사용합니다. **추천 불러오기**, 탭 전환, 티커 수동 조회, 관심종목 등록은 저장된 데이터만 읽습니다.

box score는 거래량 배수, rsi2 score는 낮은 RSI, breakout score는 ATR 대비 20일 돌파선 위치를 동점 순위에 사용합니다. 1000·trend score의 동점과 마지막 동점에는 티커 순을 사용합니다.


### Breakout
breakout score는 확정 종가가 당일 이전 20일·55일 고점을 각각 초과하면 1점씩 더합니다. 2점은 두 시스템, 1점은 시스템 1의 돌파입니다. 점수가 같으면 20일 돌파선에서 위로 떨어진 거리를 ATR 단위로 비교합니다. 과거 일봉의 OHLC는 주식분할과 기준일 전 현금배당을 반영합니다. 배당락 이전 가격에 `1 − 분할 조정 배당금 / 배당락 직전 종가`를 곱합니다. 채널과 ATR 계산에는 반올림 전 가격을 사용합니다. 추천에서 상세를 열면 추천 기준일과 해당 카드에 저장된 가격 보정 기준을 사용합니다. 20일 ATR은 와일더 평활을 사용하며, 2N 손절과 0.5N 간격 추가 진입을 종목별 배분액 기준으로 계산합니다. [첨부 화면 비교 결과](research/breakout-reference.md)를 참고하세요.


### 관심종목과 추천

나스닥 100은 Nasdaq의 구성 종목 목록을 사용하고, 조회 실패 시 위키백과의 구성 표를 확인합니다. S&P 500과 다우는 위키백과 구성 표를 사용하므로 지수 변경 반영에 시차가 있을 수 있습니다. **주요상장사**는 세 지수의 중복 티커를 합친 뒤 시가총액 하위 30%를 제외합니다. **전종목**은 기준일의 미국 거래소 상장 보통주 중 시가총액 상위 80%를 대상으로 합니다. 각 범위의 시총 순위는 확인 가능한 종목에서 별도로 계산합니다. Massive의 기준일 비조정 종가와 SEC 공시 발행주식 수를 사용하고 분할을 반영합니다. 시총 제외 수는 올림하고 경계 시총과 같은 종목도 제외합니다. 최근 180일 이내 공시에서 자본 양수와 자산 초과를 확인하고, 유동자산·유동부채가 모두 공시된 경우 유동비율 100% 이상을 요구합니다. 시총과 건전성을 검증할 수 없는 종목도 제외하며, 통과 종목이 6개 미만이면 확인된 수만 표시합니다.

예약 검색은 Massive의 기준일 보통주 목록에서 티커와 SEC 기업 식별자(CIK)를 연결하고, [Quotelinks SEC Fundamentals API](https://www.quotelinks.com/api/sec-fundamentals/)에서 공시 재무자료를 읽습니다. GitHub 실행 환경에서 SEC 직접 요청이 거절되어 공시 데이터 제공 경로를 변경했습니다. 별도의 API 키 없이 초당 2건 미만으로 요청하며, 최초 보고 기준(`basis=original`)을 사용합니다. 기준일 이후 공시, 오래된 자료, 분할 조정·추정 주식 수는 사용하지 않습니다. 공시 기간 말과 제출일 사이에 분할이 있으면 주식 수의 기준이 불확실하므로 제외합니다. 여러 보통주 티커가 같은 기업에 연결되면 기업 전체 주식 수로 개별 주식의 시총을 계산할 수 없어 추천 대상에서 제외합니다.

Quotelinks의 이용 범위는 개인의 비공개·비상업적 분석입니다. 원본 재무자료를 저장소나 공개 로그에 게시하지 않으며, 앱 결과는 개인 접근 코드로 보호합니다. 외부 사용자에게 결과를 제공하는 서비스로 변경할 때는 데이터 공급자의 사용 허가가 필요합니다. `.github/workflows/check-fundamentals.yml`은 재무 API의 응답과 날짜·분할 기준을 검사합니다. 일일 예약에서 종가와 재무 자료가 모두 준비되면 검색 결과를 저장합니다.

한 브라우저에 최대 10개 관심종목을 저장하며 탭에서 공유합니다. 등록 시 일일 수집에 포함된 미국 상장 종목 목록을 사용합니다. 연결 또는 권한 오류 시 등록하지 않습니다. 저장 결과는 기기 간 동기화되지 않습니다. 각 탭의 임시 점수는 앱에 산식이 표시되며 원본 서비스의 점수가 아닙니다. 종목별 점수는 조회 가능한 확정 일봉으로 계산합니다. 추천은 최신 완료된 자동 검색에서 선택한 범위의 전략 점수 순으로 최대 6개 표시합니다. 자료가 아직 저장되지 않은 종목은 앱에서 확인할 수 있는 기준일 또는 자료 부족 메시지를 표시합니다. 차트 이미지 보기 버튼은 해당 차트를 캡처해 보여주며, 원본 참조 화면과 픽셀 단위 일치는 보장하지 않습니다.


### 종합 탭과 PDF
종합 탭의 **3. 전략별 추천종목**에서 다섯 전략의 추천 목록과 종목별 엘리어트 파동 후보를 볼 수 있습니다. **4. 차트 읽기와 투자 자료 활용**에서 분석 화면을 안내합니다. 상세 결과의 PDF 저장은 조건과 점수, 차트, 상황별 참고를 A4 한 페이지 이미지형 PDF로 생성합니다. 항목이 많으면 요약하여 표시합니다. ATR 1유닛 위험은 설명서의 2N 손절 시 배분액의 1%를 기본으로 하며 예전 화면의 약 2%도 선택할 수 있습니다. ATR 방식과 상대강도 원본 산식은 확인되지 않았습니다. box의 30주선 기울기는 직전 주와 비교한 참고값이며 네 단계의 정식 판정은 아닙니다.


### 1000 시간대 연결
티커만 입력하면 일봉을 기본으로 표시합니다. 같은 거래일에 완결된 정규장 15분봉의 EMA1·2·3 대비 EMA5를 내부 참고 지표로 비교해 일봉 결과와 함께 표시합니다. 화면의 혼조·상승·하락은 일봉과 15분봉의 EMA 구도를 비교한 결과입니다. 데이터가 없거나 다른 날짜 또는 정규장 마지막 봉이 없으면 비교 불가로 표시합니다 (조기 폐장도 비교 불가). 1000 추천 후보의 15분봉 비교는 자동 검색에서 미리 저장합니다. 다른 종목도 저장된 일봉으로 조회하며, 15분봉 비교는 저장된 자료가 있을 때 표시합니다. 일봉으로 추천 순위를 정합니다.


### 1000 score
일봉 조건 9개에 각각 1점을 부여합니다. EMA8·13·21의 최근 5거래일 구간에서 어느 두 선이 교차하거나 맞닿으면 삼선 꼬임으로 보고 해당 조건에 점수를 부여하지 않습니다. 삼선 게이지는 상승 하이킨아시 캔들이고 하이킨아시 종가가 단기 EMA 세 개보다 높을 때 충족합니다.
