# breakout score 기준일 비교

첨부 앱 화면은 2026-11-12 확정 일봉 기준이고, 비교 화면 6건은 모두 2026-11-13 확정 일봉 기준이다. 비교 화면의 대기, 시스템 1, 시스템 1+2를 각각 0/2점, 1/2점, 2/2점으로 환산했다. [검증 실행](https://github.com/rrjrrshop-dotcom/rsi2/actions/runs/43589106562)에서 Massive의 분할 조정 일봉을 같은 기준일로 비교했다.

당일을 제외한 두 채널의 최고가를 반올림 전 확정 종가가 엄격히 초과할 때 각각 1점을 준다. 정확히 한계값에 닿으면 0점으로 본다. 추천과 상세는 돌파 판정 함수를 공유하며, 추천에서 상세를 열면 추천 기준일의 종가를 요청한다.

배분액 $100,000, 2N 손실 예산 2%에서 1유닛 주식 수의 평균 절대오차는 와일더 0.50주, 단순평균 102.50주, 지수평균 356.83주였다. 와일더로 계산하면 KINS 1,325주(비교 1,327주)와 XERS 1,442주(비교 1,441주)에서 차이가 남는다. 청산 기준에 쓰이는 20일 저점은 KINS 18.56(비교 18.51), COST 980.32(비교 978.87)였다. 이 수치들은 두 진입 조건의 점수에 포함되지 않는다.

## 현금배당과 과거 확정 종가 검증

과거 캡처 28건과 최근 9건을 기준일별로 다시 계산했다. 그중 34건에 신호와 채널 값이 모두 표시되어 있었고, 37건에 ATR·1유닛 수량·손절가가 있었다. 장중 미확정 캡처는 집계에서 제외했다. 이전 캡처의 FN 55일 고점은 원본 화면을 다시 읽어 603.09로 확인했다. [11월 13일과 수량 검증 자료](https://github.com/rrjrrshop-dotcom/rsi2/actions/runs/43612767910), [과거 28건 검증](https://github.com/rrjrrshop-dotcom/rsi2/actions/runs/43613748876)

Massive 일봉에 주식분할이 반영되어 있으므로, 각 배당락일 이전 OHLC에 `1 − 분할 조정 현금배당금 / 직전 종가`를 곱하는 후보를 비교했다. 여러 배당의 계수는 곱하며 기준일 종가와 거래량은 그대로 사용한다. 기준일 당일 현금배당을 반영한 후보는 SIRI의 20일 저점을 26.33에서 26.11로, 1유닛 수량을 1,156주에서 1,185주로 바꾸었다. 비교 화면의 저점은 26.33, 수량은 1,157주였다. 기준일 전 배당락까지 반영하는 규칙을 선택했다.
